### 4.2 套件与用例名（老师点名的四类已标）

**MockUSDC（4）**

- decimals 为 6  
- 管理员能给任意地址 mint  
- 非管理员不能 mint **（权限）**  
- 无转让限制：任何人可转已持有的 MockUSDC  

**ProjectRegistry（4）**

- register + list + get：可登记多个公司项目  
- setListed 可下架；非 owner 无法登记 **（权限）**  
- 项目 A 认购不影响项目 B 份额与金库资金 **（项目隔离）**  
- 下架后建议关闭新认购：不能 deposit，未 pause 可 redeem  

**RWAShare（7）**

- decimals 为 6  
- 未白名单 transfer 失败 **（权限 / 准入）**  
- 未白名单 transferFrom 失败 **（权限 / 准入）**  
- 双方都在白名单可以转  
- 增删白名单发出 WhitelistUpdated  
- 没有 MINTER_ROLE 的人 mint 份额失败 **（权限）**  
- setVault 拒绝零地址；非 Admin 不能 setVault **（权限）**  

**RWAVault（19）**

- 初始 nav 为 1e6  
- nav=1e6 时白名单用户 approve 后 deposit：份额约等于 assets，金库 USDC 增加  
- 未 approve 时 deposit 失败  
- 未白名单时 deposit 失败 **（权限）**  
- redeem 后份额销毁、按当前 nav 退回 USDC  
- NAV_MANAGER setNAV 成功并发 NavUpdated；非 NAV 角色调用失败 **（权限 + NAV）**  
- setNAV(+20%) 后再 deposit：份额按新 nav 换算；改价后赎回额随之变化 **（NAV 护栏边界）**  
- 先按 nav=1e6 申购，抬价后再赎回：同份额兑出更多 USDC（演示喂价影响） **（NAV）**  
- 超幅度 setNAV 失败；抬价偿付不足时 setNAV 失败 **（NAV 护栏）**  
- 非 Admin 不能 pause / unpause / distributeYield；pause/派息与 NAV 角色分钥 **（权限）**  
- 未白名单不能 claimYield；零金额 claim 失败 **（权限 + 派息）**  
- 关闭新认购后不能 deposit，未 pause 时可 redeem / claimYield；pause 后主路径失败  
- 无派息时偿付：Vault USDC >= totalSupply * nav / 1e6；nav=1e6 时相等  
- setNAV(0) 失败 **（NAV 护栏）**  
- 两人各 50% 份额，注入 100 USDC 利息，每人领约 50（允许 1 单位误差） **（派息）**  
- 无人持仓时 distributeYield 失败 **（派息）**  
- A 把份额转给 B 前双方先结息：未领利息不丢、不带走 **（派息）**  
- 注入并部分领取后：金库 USDC >= 按 nav 计价本金 + 尚未领走的利息 **（派息）**  
- 改 nav 后派息会计仍独立正确（改价不等于自动发息） **（NAV + 派息分轨）**

## 5. 安全工具结果（成员 1 提供 → 成员 5 整理）

### 5.1 Slither（已成功跑通）

**环境：** slither-analyzer 0.11.6 + solc 0.8.24  

**成功命令（仓库根目录）：**

```bash
pip install slither-analyzer
solc-select install 0.8.24
solc-select use 0.8.24

slither contracts/ --solc-remaps "@openzeppelin/=node_modules/@openzeppelin/" --filter-paths "node_modules|echidna" --exclude-dependencies --json docs/slither-raw.json
```

**结果摘要：**

| 级别 | 数量 | 处理 |
|------|------|------|
| High | 0 | — |
| Medium | 2（`incorrect-equality`：`claimYield` 的 `amount == 0`；`pendingYield` 的 `bal == 0 \|\| delta == 0`） | **误报**：业务上「无可领 / 无增量」判断 |
| Low `missing-zero-check`（`setVault`） | 已修为 `require(vault_ != address(0))`，修复后再扫消失 | |

Admin 能 `pause` / `setNAV`：**产品设计**，Slither 未标 High/Medium。见 [Slither扫描说明.md](./Slither扫描说明.md)、[slither-report.txt](./slither-report.txt)、[slither-raw.json](./slither-raw.json)。

**一次失败记录（命令写错，不是合约编不过）：** 把多个 sol 文件用逗号拼成一个 path，Slither 报 `ValueError: ... is not a file or directory.` 全文见 [slither-stderr.txt](./slither-stderr.txt)。正确用法是扫描目录 `contracts/`。

```yaml
  - "--solc-remaps"
```

**Harness：** `contracts/echidna/EchidnaRWAVault.sol`  

**环境备注：** 当时 WSL2 磁盘挂载失败，改用 Windows 二进制 `echidna-2.3.3`（解压到 `tools/echidna/`，该目录 gitignore）。需 `solc 0.8.24` 在 PATH。

**命令（PowerShell）：**

```powershell
solc-select use 0.8.24
.\tools\echidna\echidna.exe .\contracts\echidna\EchidnaRWAVault.sol --contract EchidnaRWAVault --config echidna.yaml
```

**结果（2026-10-27，全文 [echidna-run.txt](./echidna-run.txt)）：**

```

echidna_vault_solvency: passing
Unique instructions: 10936
Corpus size: 10
Seed: 160270963808111688
Total calls: 50074
```

| 属性 | 含义 |
|------|------|
| `echidna_outsider_zero_shares` | 永不入白的地址份额余额恒为 0 |
| `echidna_vault_solvency` | `USDC(vault) >= totalSupply * nav / 1e6 + 未领利息会计` |

Harness 在抬高 nav 时会向金库补足差额，以便在「已注资」前提下测会计不变量；产品上抬价不注资会走 `InsufficientReserve`，属威胁模型第 5 条，不是 fuzz 失败。
