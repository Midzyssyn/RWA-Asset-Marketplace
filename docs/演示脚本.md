# 演示路径：浏览市场 → 进项目 → 认购

> 目标：老师按清单点一遍即可验收多公司 RWA 资产市场。本地 Hardhat 或 Sepolia 均可。  
> 角色建议拆钱包：平台（Registry Owner）、项目方（Vault Admin）、投资人 A。若部署者兼任前两者，口头说明权限已按合约分离。  
> 前置：`deploy:local` 已登记 ≥3 个示例项目；建议跑过 `seed-demo.js`。  
> 规则对照：[下架与暂停对照.md](./下架与暂停对照.md)

**上调 NAV 前注意：** 抬价会使同一份额兑出更多 USDC。先看**该项目**金库 `MockUSDC` 余额是否够兑付。`setNAV` ≠ 分配收益。

---

## 顺序（约 3 分钟）

1. **浏览市场**  
   打开首页「RWA 资产市场」，应看到多家公司项目（如东海绿能 / 江城物流 / 滨海置业），各有项目名、简介、份额净值、是否可认购。

2. **进入项目 A**  
   点「查看并认购」进入 `/project/0`（或任选）。展示该公司项目详情与当前净值。

3. **管理员发测试币 + 投资者准入**  
   Admin → 选中项目 A → Mint mUSDC 给投资者 A → **投资者准入**（白名单）。  
   （说明：准入按项目隔离，A 准入不自动等于项目 B 准入——`seed-demo` 会给全部项目准入。）

4. **投资人认购项目 A**  
   Approve → 认购资产项目 → 本项目份额增加。  
   **验收：** 项目 B 的份额余额与金库资金仍为 0 / 不变。

5. **管理员只改项目 A 的净值**  
   Admin 对项目 A `更新项目份额净值`（如 `1.05`）。  
   **验收：** 项目 B 的净值仍为 1.0；A 的申购/赎回预估随 nav 变化。

6. **（可选）分配 / 领取项目收益**  
   Admin 对 A `分配项目收益`；投资者在项目页 `领取收益`。派息与 setNAV 分轨。

7. **（可选）暂停柜台**  
   项目方暂停项目 A；投资人再认购 / 赎回 / 领息应失败。项目 B 不受影响。

8. **（可选）对照：下架 ≠ 暂停**  
   平台对 A `下架`：市场列表看不到 A；直达 `/project/0` 时不可新认购，但未 pause 时仍可赎回/领息。再 `暂停` 则赎回也停。

---

## 彩排提示

- 主路径保留：市场列表 → 进项目 → 准入 → 认购 → 改 A 的 NAV 看 B 不变。  
- 口头诚实边界：MockUSDC、教学演示、每项目中心化净值、下架≠暂停、范围外含真 KYC / 主网证券 / 二级订单簿 / Chainlink。  
- 演示账户私钥不要投屏、不要提交仓库。
