## 1. 市场下架 vs 柜台暂停（对照表）

| | 市场下架 `setListed(false)` | 柜台暂停 `pause()` |
|---|---|---|
| 层级 | `ProjectRegistry` + 建议联调 `RWAVault.setDepositsOpen(false)` | 该项目 `RWAVault` |
| 操作者 | 平台 Registry Owner；关认购为项目 Vault Admin | 项目 Vault Admin |
| 对新客 | 市场不可见；链上 `depositsOpen=false` 时 **deposit 失败** | 全部柜台操作停止 |
| 对已持有 | 仍可赎回与领息（若未再 `pause`） | 赎回 / 领息也停 |
| 是否改资金锁定逻辑 | 关认购只挡 `deposit` | 是（`Pausable`） |

### 实现要点（避免概念混淆）

- **`setListed`**：只改目录字段 `listed`（市场默认过滤未上架；详情可提示已下架）。**不**自动调用 Vault `pause`。
- **`setDepositsOpen(false)`**（项目方 Admin）：链上拒绝新 `deposit`；**`redeem` / `claimYield` 在未 pause 时仍允许**。Admin 页下架时若当前账户是 Vault Admin，会联调关闭认购。
- **`pause` / `unpause`**：OpenZeppelin `Pausable`。`deposit` / `redeem` / `setNAV` / `distributeYield` / `claimYield` 均挂 `whenNotPaused`；暂停后该项目柜台写操作**链上强制**失败，其它项目不受影响。
- **二者可叠加**：先下架再暂停时，已持有者也无法赎回 / 领息，直到项目方 `unpause`。

## 2. `setNAV` 规则边界

| 规则 | 说明 |
|------|------|
| 中心化喂价 | 持有 **`NAV_MANAGER_ROLE`** 者链上提交净值；**≠ Chainlink**；Admin 可授此角色（与 pause/派息分钥） |
| 只改本金兑换价 | `setNAV` 更新 `nav`，影响申购 / 赎回换算；**≠ 分配收益**（派息走 `distributeYield` / `claimYield` 与 `rewardIndex`，分轨禁止混用） |
| 护栏 | `newNav > 0`；单次相对变动 **≤ ±20%**；**抬价**时 `USDC.balanceOf(vault) >= totalSupply * newNav / 1e6 + 未领利息`，不够则 revert（先注资） |
| 信任假设 | 信任落在**持有该项目 `NAV_MANAGER_ROLE` 私钥**的人；可在护栏内抬价 / 压价 |
| 偿付约束 | 抬价使同份额赎回额上升；护栏强制先有足够 USDC，否则无法上调 |

链上硬约束（教学级）：`onlyRole(NAV_MANAGER_ROLE)`、`newNav > 0`、±20%、抬价偿付、`whenNotPaused`。报告须写明操纵风险属产品设计披露，不是「漏接预言机」。威胁表第 5 条写清角色拆分与护栏。

## 3. 角色边界

| 角色 | 链上身份 | 能做什么 | 不能做什么 |
|------|----------|----------|------------|
| **平台** | `ProjectRegistry` Owner | 登记项目、上架 / 下架（`registerProject` / `setListed`） | 不代替项目方改白名单、`setNAV`、派息、`pause`（除非同一地址兼任） |
| **项目方 Admin** | 该项目 `DEFAULT_ADMIN_ROLE` | 投资者准入、分配收益、暂停 / 恢复、`setDepositsOpen`、**授予/撤销 `NAV_MANAGER_ROLE`** | 无 NAV 角色时**不能** `setNAV`；不能改其它项目 Vault |
| **净值经理** | 该项目 `NAV_MANAGER_ROLE` | **仅 `setNAV`**（受护栏约束） | 不能 `pause` / `distributeYield` / 改白名单（除非兼任 Admin） |
| **投资人** | 已准入地址 | 认购、赎回、领收益（须该项目白名单；认购还须 `depositsOpen`） | 不能 mint 份额、不能改 NAV、不能暂停 |

**谁能改净值：** 仅地址持有该项目 Vault 的 `NAV_MANAGER_ROLE`。部署时 Admin 默认持有；演示脚本可将角色另授给第二演示账户，体现与 pause/派息分钥。

**演示建议：** 用**不同钱包**分别演示「平台 vs 项目 Admin vs NAV 经理 vs 投资人」；答辩说明「权限在合约上已拆分」。

## 4. 范围外（报告写死）

本作业**明确不做**：

- 真实 KYC / 证件存储与核验  
- 真美元、主网真实证券发行  
- 二级订单簿 / 项目间公开转让撮合  
- 跨项目合并金库（巨无霸单池）  
- 外部预言机（含 Chainlink）

诚实对照：白名单 ≠ 真 KYC；MockUSDC ≠ 真美元；`setNAV` ≠ 去中心化预言机；下架 ≠ 暂停。
